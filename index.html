CHUNK

A multiband channel processor — EQ, COMP, and spectral RS sharing one frequency graph.

See what it does

The first plugin

Shape the whole channel without leaving the graph.

CHUNK stacks an 8-band EQ, 6-band compressor, and a split-band spectral compressor (RS) on a shared spectrum view — so you carve, control, and clean in the same place.

In → Harmonics → EQ → COMP → RS → Width → Out

Three layers

One graph. Three jobs.

EQ

Eight bands of surgical tone

Bell, shelves, high/low pass, and plateau filters — drag nodes on the spectrum, solo bands, and sculpt without jumping between plugins.

COMP

Six-band dynamics with sidechain

Threshold, ratio, attack, release, knee, makeup, range, and gate per region — plus external sidechain when you need to duck with intention.

RS

Spectral compression that follows the sound

RS splits each region into ~80 narrow log-spaced bands that compress independently — gain reduction traces the inverse of the spectrum for transparent leveling and resonance control.

Around the edges

Input color. Output polish.

  • Input & output harmonic drive with even/odd balance
  • Stereo width and continuous phase control
  • Output ceiling / brickwall for clean peaks
  • Live spectrum analyzer under every layer
  • VST3 for Windows (macOS AU coming later)
